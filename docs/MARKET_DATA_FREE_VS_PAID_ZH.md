# 全球市场信息源：免费与付费边界

更新于 2026-08-16。本文描述的是独立市场信息产品，不包含任何经纪商账号、
交易、持仓或下单能力。

| 能力 | 免费路径 | 付费路径 | 当前状态 |
|---|---|---|---|
| 新闻 | Yahoo / Google RSS | 专业新闻终端 | 多数市场可用，但不等于法定披露 |
| 美国披露 | SEC | — | live |
| 多国披露 | 交易所/监管机构公开 API、CSV、RSS | 官方 OAM 或商业数据包 | 约半数 live，其余明确标 partial/stub |
| 证券目录 | 交易所公开目录 | 完整证券主数据许可 | 约半数 live |
| ETF 目录 | 少数交易所公开目录 | 完整 ETF 主数据 | DE/JP/US live |
| ETF 法律文件 | 少量公开网页 | 基金/交易所文件 API | 当前 0 国 live |
| 第三方补洞 | CEO.ca、StocksSG、OpenFIGI 等 | 获许可的数据商 | 必须标明 third_party 与完整性边界 |

当前 28 国 / 87 个参考场所标签只用于衡量覆盖面，不是运行时经纪商依赖，
也不能证明可交易。产品不需要 IBKR API、Gateway、TWS、Client Portal 或
`conid`。

优先级始终是：官方免费源 > 正规第三方 > 获许可付费源。若没有稳定且许可
允许的来源，就保持 partial/stub，不把新闻、搜索结果或账户权限冒充披露。
